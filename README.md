## 📖 परिचय / Overview

**हिन्दी फॉन्ट महा-संग्रह (Hindi Fonts Mega Archive)** एक विशाल, सुव्यवस्थित और आधिकारिक फॉन्ट संग्रह है जिसमें **6,009 से अधिक उच्च गुणवत्ता वाले हिन्दी एवं देवनागरी फॉन्ट** शामिल हैं। 

यह संग्रह भारत के लाखों सरकारी नौकरी परीक्षार्थियों, डीटीपी प्रिंटिंग प्रेस प्रकाशकों, ग्राफिक डिजाइनरों, यूआई/ইউএক্স ডেভেলপার এবং গবেষকদের জন্য তৈরি একটি ওয়ান-স্টপ সমাধান।

The **Hindi Fonts Mega Archive** is the most extensive and verified typographic repository for Devanagari script on GitHub, uniting:
1. **Legacy Remington Typewriter Fonts:** Kruti Dev, DevLys, Shree-Lipi (Shree-Dev), and Chanakya required for government typing examinations (SSC CGL/CHSL, Allahabad/Rajasthan High Court, MP CPCT, UP Police) and traditional offset press publishing (Adobe PageMaker, CorelDraw).
2. **Modern Unicode Typefaces:** Poppins, Kalam, Rajdhani, Mukta, Baloo 2, Hind, and Noto Sans Devanagari designed for modern responsive websites, Android/iOS mobile apps, social media graphics, and digital publishing.
3. **Artistic & Calligraphic Fonts:** AMS Calligraphy, Abbasi, Bhartiya, and KBC font families for wedding cards, flex banners, political posters, and Bollywood title typography.
4. **Classical Vedic & Sanskrit Fonts:** Sanskrit 2003, Chandas, Siddhanta, and Nakula containing complex ligatures, conjuncts, and Vedic Svara accent markers.

## ⌨️ टाइपिंग कीबोर्ड गाइड / Typing Keyboard Layout Guide

हिन्दी भाषा में टाइपिंग के लिए दो प्रमुख कीबोर्ड प्रणालियाँ उपयोग की जाती हैं:

### 1. गैर-यूनिकोड रेमिंगटन लेआउट (Non-Unicode Remington Typewriter Layout)
* **समर्थित फॉन्ट:** `Kruti Dev (कृति देव)`, `DevLys (देवलीस)`, `Shree-Lipi (श्री-लिपि)`, `Chanakya (चाणक्य)`।
* **परीक्षाएँ एवं उपयोग:** SSC CGL/CHSL, इलाहाबाद उच्च न्यायालय, राजस्थान उच्च न्यायालय, मध्य प्रदेश CPCT, उत्तर प्रदेश पुलिस लिपिक परीक्षा।
* **मैपिंग नियम:** अंग्रेजी की-बोर्ड के अक्षरों पर हिन्दी वर्ण मैप होते हैं:
  * `d` = क, `k` = ा की मात्रा, `s` = े की मात्रा, `w` = ू की मात्रा, `j` = र, `v` = अ, `h` = भ।

### 2. मानकीकृत यूनिकोड इन्स्क्रिप्ट लेआउट (Standard Unicode Inscript Layout)
* **समर्थित फॉन्ट:** `Mangal (मंगल)`, `Poppins`, `Rajdhani`, `Kalam`, `SakalBharati`।
* **अनुमोदन:** भारत सरकार (C-DAC / GIST) एवं यूनिकोड कंसोर्टियम द्वारा स्वीकृत।
* **उपयोग:** आधुनिक वेब ब्राउज़र, एमएस वर्ड 2021/365, गूगल डॉक्स, यूट्यूब, फेसबुक, व्हाट्सएप।

## ⚙️ संस्थापन निर्देशिका / Installation Instructions

### Windows 10 / 11:
1. अपनी पसंद के सब-फ़ोल्डर में जाएँ।
2. सभी `.ttf` या `.otf` फ़ाइलों को चुनें (`Ctrl + A`)।
3. राइट-क्लिक करें और **"Install"** या **"Install for all users"** पर क्लिक करें।

### macOS:
1. फ़ॉन्ट फ़ाइलों पर डबल-क्लिक करें।
2. **"Install Font"** बटन दबाएँ, अथवा सभी फ़ाइलों को **Font Book** ऐप में ड्रैग करें।

### Linux (Ubuntu / Debian / Fedora / Arch):
```bash
# Create dedicated Hindi fonts directory
mkdir -p ~/.local/share/fonts/hindi

# Copy downloaded fonts into font directory
cp *.ttf *.otf ~/.local/share/fonts/hindi/

# Rebuild font cache
fc-cache -f -v
```

## ❓ अक्सर पूछे जाने वाले सवाल / Frequently Asked Questions (FAQ)

#### Q1: SSC और High Court टाइपिंग टेस्ट के लिए कौन सा फॉन्ट चाहिए?
**उत्तर:** अधिकांश सरकारी टाइपिंग परीक्षाओं में **`Kruti Dev 010`** अथवा **`DevLys 010`** (रेमिंगटन लेआउट) का उपयोग किया जाता है। दोनों फॉन्ट `01_Legacy_KrutiDev_Series` और `02_Legacy_DevLys_Series` फ़ोल्डर में उपलब्ध हैं।

#### Q2: क्या ये फॉन्ट Photoshop, CorelDraw और Premiere Pro में चलेंगे?
**उत्तर:** हाँ, संग्रह के सभी 6,009 फॉन्ट TrueType (.ttf) और OpenType (.otf) मानक पर आधारित हैं जो Adobe Photoshop, Illustrator, Premiere Pro, InDesign এবং CorelDraw-তে সম্পূর্ণ সমর্থন করে।

#### Q3: यूनिकोड टेक्स्ट को कृति देव में कैसे बदलें?
**उत्तर:** आप इंटरनेट पर उपलब्ध किसी भी मुफ्त ऑनलाइन "Unicode to Kruti Dev Converter" टूल का उपयोग करके अपने टेक्स्ट को आसानी से कन्वर्ट कर सकते हैं।
